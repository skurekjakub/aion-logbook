제 1 조 (목적)

이 약관은 주식회사 엔씨(이하 ‘회사’)와 이용자 간에 회사가 제공하는 API Service와 관련한 회사와 이용자의 권리, 의무 및 책임에 관한 제반 사항과 기타 필요한 사항을 구체적으로 규정함을 목적으로 합니다.

제 2 조 (용어의 정의)

이 약관에서 사용하는 용어의 정의는 다음과 같습니다.

1. ‘API’란 Application Programming Interface의 약자로서 이용자가 본인의 애플리케이션 등에서 회사가 제공하는 기술을 사용하기 위한 인터페이스를 의미합니다.

2. ‘API Service’란 회사가 API를 이용자에게 제공하는 것을 의미합니다.

3. ‘이용자’란 회사의 게임서비스 이용약관에 따라 이용신청 및 이용계약 체결을 완료한 회원 중, 본 약관에 따라 회사와 이용계약을 체결하고 회사가 제공하는 API Service를 이용하는 자를 의미합니다.

4. ‘애플리케이션 등’이란 이용자가 API Service를 적용시키고자 하는 이용자의 애플리케이션, 프로그램 또는 웹사이트 등을 의미합니다.

5. ‘개발자센터’라 함은 회사의 API Service 제공 웹사이트(https://developers.plaync.com)를 의미합니다.

6. ‘API Key’란 이용자가 API Service를 이용하기 위해 회사로부터 발급받는 고유한 인증 값을 의미합니다.

② 회사는 필요한 경우 관련 법령에 위배되지 않는 범위 내에서 본 약관을 개정할 수 있으며, 약관 개정 시 그 적용일 7일 이전부터 약관의 개정내용 및 적용일자를 개발자센터를 통해 공지합니다. 다만, 약관이 이용자에게 불리하게 개정되는 경우 그 적용일 30일 이전부터 개발자센터를 통해 공지하거나, 이용자가 회사의 게임서비스 이용약관에 따라 이용계약 체결 시 등록한 전자우편 주소가 있을 경우 그 전자우편으로 전송하는 방법으로 이용자에게 통지합니다. 개정된 약관은 그 적용일자부터 효력이 발생합니다.

③ 회사는 약관 개정 시 개정약관 공지 이후 개정약관의 적용에 대한 이용자의 동의 여부를 확인합니다. 회사는 제2항의 공지 또는 통지를 할 경우 이용자가 개정약관에 대해 동의 또는 거부의 의사표시를 하지 않으면 개정에 동의한 것으로 볼 수 있다는 내용도 함께 공지 또는 통지를 하며, 이용자가 개정약관 적용일까지 거부의 의사표시를 하지 않을 경우 개정약관의 적용에 동의한 것으로 볼 수 있습니다.

④ 이용자는 개정약관의 적용에 동의하지 않는 경우 API Service 이용을 중단할 수 있습니다.

① 회사는 API Service를 제공함에 있어 API Service의 범위, 이용 가능 시간, 이용 가능 횟수, 이용 요금 등을 지정할 수 있고, 이와 같은 제공 조건을 개발자센터를 통해 공지하며, 이용자는 그와 같이 정해진 조건에 따라서만 API Service를 이용할 수 있습니다.

② 회사의 무료 API Service 제공은 어떠한 경우에도 회사와 이용자 간 제휴 관계의 성립을 의미하지 않습니다.

③ 회사가 유료 API Service를 제공하는 경우, 회원은 회사와 별도 유료이용계약을 체결한 후 유료 API Service를 이용할 수 있습니다. 상세한 유료 API Service의 내용은 별도 유료이용계약 및 개발자센터 내 유료정책 설명 페이지를 통해 확인할 수 있습니다.
